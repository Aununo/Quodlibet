# Quodlibet

基于 Claude 的 PPT 答辩练习应用：上传 PPT → AI 扮演多视角评委出题 → 你作答 → AI 追问 / 打分 / 给出更优答法。

> Quodlibet（拉丁语「随你所问」）原指中世纪经院辩论中观众可以任意发问的环节，正好对应本应用的核心场景。


## 🧭 业务流程

```
┌──────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ 1. 上传 PPT  │ → │ 2. 浏览器解析文本 │ → │ 3. 分段总结(SSE) │
└──────────────┘   └──────────────────┘   └────────┬─────────┘
                                                   ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 生成 N 道评委问题（带参考要点 reference_points）          │
└────────────────────────────┬────────────────────────────────┘
                             ▼
   ┌────────────────────────────────────────────────────────┐
   │ 5. 用户答题（文字 / 语音转写均可）                       │
   └───────────────────────────┬────────────────────────────┘
                               ▼
   ┌────────────────────────────────────────────────────────┐
   │ 6. 评委一次性返回 follow_up + evaluation                │
   │    - 若有 follow_up：进入追问轮                         │
   │    - 否则：直接 0–10 分 + highlights / gaps / 更优答案   │
   └────────────────────────────────────────────────────────┘
```
